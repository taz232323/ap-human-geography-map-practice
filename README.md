# AP Human Geography map practice

This GitHub Pages repository hosts self-contained geography quizzes that can be shared with anyone who has the link.

## Published quizzes

- [United States and Canada](https://taz232323.github.io/ap-human-geography-map-practice/)
- [Latin America](https://taz232323.github.io/ap-human-geography-map-practice/latin-america/)

## Adding another map

1. Create a short, lowercase folder name, such as `africa` or `europe`.
2. Place that quiz's self-contained HTML file inside the folder as `index.html`.
3. Commit and push the folder to the `main` branch.
4. Share `https://taz232323.github.io/ap-human-geography-map-practice/FOLDER-NAME/`.

Each person's saved progress stays in their own browser. Sharing a quiz link does not mix their scores or missed-location history with anyone else's.
